# ncodex relay — свой сервер с постоянным адресом

```
Notion ──HTTPS──▶ свой сервер (relay) ◀──WebSocket── ncodex на компьютере
```

С quick tunnel от Cloudflare адрес меняется после каждого перезапуска, и в Notion приходится заново
вписывать ссылку. Со своим сервером адрес один и навсегда: `https://<имя>.onrender.com/mcp/<токен>`.

Как это работает: ncodex на компьютере сам подключается к серверу исходящим соединением (как браузер к
сайту), поэтому не нужны белый IP, проброс портов на роутере и сторонние туннели. Notion шлёт запрос на
сервер, сервер передаёт его в ncodex и возвращает ответ.

Безопасность:

* сервер **ничего не хранит** — ни файлов, ни запросов; токен из ссылки Notion он не пишет даже в журнал;
* подключиться к серверу «как компьютер» можно только с **секретом** (`RELAY_SECRET`), он есть только
  у тебя в ncodex и в настройках Render;
* запросы Notion по-прежнему проверяет сам ncodex: без правильного токена в ссылке они не пройдут,
  а все правила доступа к папкам и командам работают как раньше.

## Как поднять на Render (бесплатно, минут 10)

Понадобятся аккаунты на [GitHub](https://github.com) и [Render](https://render.com) (на Render удобнее
всего входить через GitHub). Если сайты не открываются — включи Happ.

1. **Секрет.** Окно ncodex → **Настройки → Туннель → Свой сервер (Render)** → у поля «Секрет» нажми
   **Скопировать**. В терминале его покажет `ncodex relay`.
2. **Репозиторий на GitHub.** Открой [github.com/new](https://github.com/new): имя, например,
   `ncodex-relay`, можно **Private**, галочки ниже не ставь → **Create repository**. На следующей
   странице нажми ссылку **uploading an existing file** и перетащи в браузер файлы из папки сервера
   (в окне ncodex — ссылка «папка с файлами сервера», обычно это `~/.local/share/ncodex/relay`):
   `relay.py`, `requirements.txt`, `render.yaml`, `Dockerfile`, `README.md` → **Commit changes**.
   Перетаскивай сами файлы, а не папку целиком: `render.yaml` должен лежать в корне репозитория.
3. **Сервер на Render.** [dashboard.render.com](https://dashboard.render.com) → **New → Blueprint** →
   выбери репозиторий `ncodex-relay` (если его нет в списке — «Configure GitHub» и дай Render доступ
   к нему) → имя Blueprint любое → в поле **RELAY_SECRET** вставь секрет из шага 1 →
   **Deploy Blueprint**. Сборка занимает 1–3 минуты.
4. **Адрес.** Render → сервис **ncodex-relay** → вверху адрес вида `https://ncodex-relay.onrender.com`
   (если имя занято, Render добавит к нему несколько букв) → скопируй.
5. **ncodex.** Настройки → Туннель → Свой сервер → вставь адрес в «Адрес сервера» → **Проверить сервер**
   → **Сохранить**. Через несколько секунд вверху окна появится «на связи» и адрес сервера.
6. **Notion.** Нажми «Ссылка для Notion» и обнови ссылку в подключении Notion — **в последний раз**:
   дальше она не меняется ни после перезапуска ncodex, ни после перезагрузки компьютера.

То же из терминала: `ncodex relay --url https://ncodex-relay.onrender.com --check`, потом перезапусти
ncodex (кнопка «Перезапустить ncodex» в окне или `ncodex restart`, если он работает службой).

### Если Blueprint не получается

Можно создать сервис вручную: **New → Web Service** → репозиторий `ncodex-relay` →

* Language: **Python 3**;
* Build Command: `pip install -r requirements.txt`;
* Start Command: `python relay.py`;
* Instance Type: **Free**;
* Environment Variables: `RELAY_SECRET` = секрет из ncodex, `PYTHON_VERSION` = `3.13.5`;
* Advanced → Health Check Path: `/_ncodex/ping`

→ **Deploy Web Service**.

## Что надо знать про бесплатный Render

* Бесплатный сервер **засыпает через 15 минут** без входящих запросов и просыпается примерно за минуту.
  Пока ncodex запущен, он держит соединение и раз в 8 минут сам «будит» сервер, так что в работе сервер
  не спит. Если компьютер был выключен, сервер заснёт; после включения ncodex разбудит его сам —
  первое подключение может занять до минуты.
* Render даёт **750 бесплатных часов в месяц** на аккаунт. Одному серверу этого хватает на весь месяц
  круглосуточно (в самом длинном месяце 744 часа). Если на Render есть другие бесплатные сервисы,
  часы у них общие.
* Render может перезапустить бесплатный сервер в любой момент — ncodex переподключится сам за несколько
  секунд.
* Когда компьютер выключен или ncodex не запущен, Notion получит ответ «Компьютер не в сети…».
* К одному серверу подключается один компьютер. Если запустить ncodex с тем же секретом на втором
  компьютере, он «перехватит» сервер, а в журнале первого появится предупреждение.

## Проверка

* `https://<адрес>/_ncodex/ping` в браузере → `ok` (сервер работает);
* `ncodex relay --check` → подключён ли компьютер, версия relay;
* `curl -H "Authorization: Bearer <секрет>" https://<адрес>/_ncodex/status` → JSON, `"agent": true`
  значит, что компьютер на связи;
* журнал сервера: Render → сервис → **Logs** (видно подключения компьютера и запросы, токены скрыты).

## Новый секрет

Окно ncodex → Настройки → Туннель → Свой сервер → **Новый…** → **Скопировать**. Потом Render → сервис →
**Environment** → `RELAY_SECRET` → вставь новое значение → **Save, rebuild, and deploy**. Пока секреты
не совпадают, ncodex пишет в журнал «свой сервер не принял секрет» и пробует раз в минуту.
Ссылка для Notion при этом не меняется.

## Если что-то не так

| в журнале ncodex | что сделать |
|---|---|
| «свой сервер не принял секрет» | секрет в Render (Environment → `RELAY_SECRET`) не совпадает с секретом в ncodex |
| «на своём сервере не задан RELAY_SECRET» | добавь `RELAY_SECRET` в Render → Environment |
| «по адресу … нет ncodex relay» | неверный адрес или сервис в Render не запущен / удалён |
| «сервер ответил через … с — бесплатный Render просыпался» | всё в порядке, так бывает после сна |
| ошибки соединения, таймауты | Render может быть недоступен без VPN: включи Happ, а в ncodex оставь «Прокси: авто» |

## Другие хостинги

Подойдёт любой хостинг, где есть HTTPS и WebSocket: для хостингов с Docker (Koyeb, Fly.io, свой VPS…)
есть `Dockerfile`. Переменные окружения: `RELAY_SECRET` (обязательно, не короче 24 символов),
`PORT` (порт, по умолчанию 8080), `REQUEST_TIMEOUT` (сколько ждать ответа компьютера, по умолчанию 300 с).

На своём VPS без Docker: `pip install aiohttp`, `RELAY_SECRET=… python3 relay.py`, а снаружи — nginx или
Caddy с HTTPS (адрес в ncodex должен начинаться с `https://`; для WebSocket в nginx нужны заголовки
`Upgrade` и `Connection`).
